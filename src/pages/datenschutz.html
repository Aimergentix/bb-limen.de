Die DSGVO nennt jeden Umgang mit Daten verarbeiten. Dazu gehört zum Beispiel: Daten sammeln, speichern, verwenden, weitergeben oder löschen.

Wenn Sie diese Website besuchen

Diese Website setzt keine Cookies. Cookies sind kleine Dateien, die eine Website auf Ihrem Gerät speichert. Die Website lädt auch keine Inhalte von anderen Anbietern.

Wenn Sie die Website aufrufen, schickt GitHub sie an Ihren Browser. GitHub ist eine Firma in den USA: GitHub, Inc. Ihr Dienst dafür heißt GitHub Pages. Dabei verarbeitet GitHub jedes Mal die Daten, die Ihr Browser technisch mitschickt. Das ist vor allem die IP-Adresse, also die Adresse Ihres Geräts im Internet.

Die Rechtsgrundlage dafür ist Art. 6 Abs. 1 lit. f DSGVO. Eine Rechtsgrundlage ist die Stelle im Gesetz, die eine Verarbeitung erlaubt. Diese Stelle erlaubt eine Verarbeitung, wenn sie für ein berechtigtes Interesse nötig ist. Ihre eigenen Interessen und Rechte dürfen dabei nicht schwerer wiegen. Das berechtigte Interesse ist hier: Die Website soll sicher laufen.

Wie lange GitHub diese Daten speichert, bestimmt GitHub. GitHub veröffentlicht dafür keine feste Frist.

Die Daten gehen dabei in die USA. Dafür gibt es einen Beschluss der Europäischen Kommission, den Angemessenheitsbeschluss. Danach sind Daten bei Firmen in den USA ausreichend geschützt, wenn die Firma nach dem EU-US Data Privacy Framework zertifiziert ist. GitHub ist so zertifiziert.
